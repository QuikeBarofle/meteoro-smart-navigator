# Meteoro Smart Navigator v0.2.4

Modelo experimental, educativo e informativo independiente.

## v0.2.4
- Critical Illness: tarifas Florida cargadas desde la hoja EXP 07/26.
- Planes disponibles: Básico, Mejorado y Mejorado Plus.
- Mejorado Plus queda seleccionado por defecto.
- Monto nominal seleccionable: $5,000–$100,000 en incrementos de $5,000.
- Default de trabajo del Navigator: $20,000, modificable por el agente.
- Cálculo por edad del titular, fumador/no fumador, composición y modalidad tarifaria.
- Las celdas sin tarifa publicada nunca se estiman.
- Login temporal continúa retirado.

## Prueba funcional
La aplicación necesita un navegador que ejecute JavaScript. Para validación real, usar GitHub Pages, Safari, Chrome o Edge. Algunos visores internos de archivos muestran el diseño pero bloquean botones, pestañas y cálculos.
